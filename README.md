## 🚀 核心功能與特色

- ⚡ **100% 離線原生運行**：卡片文字、提示詞 (Comments)、預覽縮圖 (`assets/images/`) 及下載檔案 (`assets/files/`) 全部鏡像存於本地，雙擊 `start.bat` 或 `index.html` 即開即用。
- 🖥️ **三大檢視模式 (View Modes)**：
  - 📋 **分欄看板 (Board Shelves)**：還原 Padlet 橫向捲動的多欄式陳列，上方提供分欄快速跳轉下拉選單。
  - 🧩 **瀑布網格 (Grid View)**：自適應多欄網格，適合大螢幕綜覽與閱讀。
  - 📝 **精簡條列 (List View)**：高密度資訊清單，迅速掃描所有卡片標題、分欄與主題標籤。
- 🔍 **智慧即時搜尋**：按鍵盤 `/` 鍵即可快速聚焦搜尋框，同時搜尋卡片標題、內文、所屬分欄與底下所有提示詞備註，即時高亮（Highlight）關鍵字。
- 🎨 **色彩分類標籤過濾**：依口訣快速過濾資料、範例、工具與實作四大類別，計數徽章動態連動更新。
- 🎲 **隨機抽籤 (Random Draw)**：內建靈感小幫手，隨機挑選一張卡片並開啟詳細彈窗。
- 📊 **Excel 相容 CSV 匯出**：點擊右上角即可一鍵將當前看板之卡片結構、分類、正文、提示詞與附件清單匯出為 UTF-8 BOM CSV 檔案。
- 🌓 **深色 / 淺色模式切換**：完美支援深色暗黑風格與乾淨淺色風格，切換時連帶調整背景半透明遮罩與壁紙疊加效果。

## 🚀 快速開啟方式

- **方式 1（直接點開）**：直接雙擊 [**`start.bat`**](./start.bat) 或以任何現代瀏覽器開啟 [**`index.html`**](./index.html)。
- **方式 2（本機靜態伺服器）**：
  ```bash
  # Node.js
  npx serve .
  
  # 或使用 Python
  python -m http.server 8080
  ```
